# 心理健康工作政策文件题库（网页版）

面向广东省中小学心理教师专业能力大赛备赛的在线练习题库。题目依据大赛考核范围内的公开政策文件整理命制，打开网页即可练习，无需安装。

- 更新日期：2026-10-19
- 当前版本：1490 题 / 9 套模拟卷

## 一、题库概况

- 覆盖政策文件：15 份
- 总题量：**1490 题**
  - 练习题：590 题（单选 432、多选 158）

- 每套题型顺序：第 1—80 题单选，第 81—100 题多选
- 模拟考试时长：60 分钟

## 二、主要功能

### 练习模式

- 文件卷多选下拉筛选，每卷括注题量，并显示当前选择范围；
- 单选、多选分题型标注，提交后即时判分；
- 每道题附解析与原文出处；
- 支持逐题练习与整卷浏览；
- 可打印当前范围的带答案版；
- 完成作答后显示成绩与错题列表，可点击跳转回顾；
- 错题本自动收录、只练错题、答对移出；
- 学习进度记录、历史进度归档、导出/导入学习记录。

### 模拟考试

- 入口：模拟考试；
- 可选 9 套卷，每套 100 题；
- 60 分钟倒计时；
- 答题卡可跳题，多选题单独标色；
- 交卷后统一评分，显示分数、正确率、用时和逐题解析；
- 答错题自动加入错题本；考试答案不计入练习进度。

## 三、使用方法

### 在线使用（推荐）

将 `index.html` 部署到 GitHub Pages 后，把网页地址发给老师即可在线练习，例如：

```
https://<用户名>.github.io/<仓库名>/
```

### 本地使用

下载 `index.html`，用浏览器（Chrome、Edge 等）直接打开即可。

## 四、目录结构

发布仓库只需包含以下三个文件：

```
.
├── index.html   # 题库网页（将本仓库的网页版 HTML 重命名/复制为 index.html）
├── README.md
└── LICENSE
```

题库数据已内嵌在 `index.html` 中，不需要额外的 JSON 或数据库文件。

## 五、数据说明与使用限制

1. **练习题与模拟卷是两套数据**：练习题 590 题；模拟卷 900 题。
2. **模拟题 6、7 是新增题**，与练习题不重复。
3. **重组巩固卷 1、2 来自原有 590 道练习题**，两套之间不重复用题，但会与练习模式内容重复；这是“巩固卷”的设计前提。
4. 因此，**巩固卷分数不能与新增模拟题 6、7 的分数直接比较**，前者更接近“做过的题再练”，后者更接近“新题模拟”。
5. 原有模拟题 1—5 的内部重复情况未在本轮清理；不同套次分数也不完全可比。
6. 旧版模拟题 8—10 存在题干泄题、同考点换壳和同选项同答案问题，已从网页题库移除；相关 xlsx 仅作审计材料，不应使用。
